# Security

Please don't post API keys, recordings, transcripts, or exploitable security details in a public issue.

Use GitHub's **Security → Advisories → Report a vulnerability** if private reporting is enabled for this repository. Otherwise open an issue asking for a private reporting channel without including vulnerability details or sensitive data.

Revoke an exposed provider key in its provider dashboard and replace it in Hall-e. Removing a key from Hall-e only removes the local Keychain item; it does not revoke the provider credential.
