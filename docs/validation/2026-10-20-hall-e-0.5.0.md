# Hall-e 0.5.0 / Android 0.2.0 candidate validation

Candidate snapshot for Hall-e **0.5.0, macOS build 2026102007** and Hall-e for
Android **0.2.0, version code 2**. These versions are not public releases. The
prior [0.4.0 validation record](2026-10-20-hall-e-0.4.0.md) remains the historical
record for that candidate; its Android behavior and package evidence do not
describe this update.

## Candidate scope

- The Mac and Android apps can pair trusted devices into a shared workspace.
  Selected meeting titles, optional project names and links, and scheduled times
  are encrypted on device before sharing. The coordinator stores ciphertext and
  coordination metadata; it does not receive audio or the decryption key.
- Android 0.2.0 adds explicit, optional phone-microphone recording and shared
  meeting coordination. Audio stays in app-private storage on the recording
  device. A shared recording requires an exclusive short-lived lease; a handoff
  request only asks the current recorder to stop, and the target device still
  requires its own user action and microphone permission.
- The shared feature is not full calendar, notes, project-library, or audio
  synchronization. A shared meeting's selected encrypted project name may be
  coordinated across devices. There is no Hall-e user account system.
