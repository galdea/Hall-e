# Help Hall-e grow 🤖

Thanks for stopping by. Small, focused pull requests are welcome.

1. Open an issue explaining the user problem, or pick an existing one.
2. Fork the repository, create a branch, and make your change.
3. Run `make test` and `make app` on macOS with Swift 6. For UI/audio changes, launch the packaged app and try the affected workflow.
4. Explain what changed and how you checked it in your pull request.

Use fictional fixtures. Never attach API keys, private recordings, transcripts, calendar exports, or personal project data. Don't run paid provider requests in automated tests. Preserve existing user data and keep cloud processing opt-in.

Please be kind, specific, and patient. English and Spanish are both welcome. 🇨🇱
